# Wallet Point Checker

เว็บเช็ก Wallet Point คงเหลือของ Username ที่ติดตาม แยกตาม 4 เซิร์ฟเวอร์: CBPC-SEA / CBPC-TH / CBM-SEA / CBM-TH

## วิธีใช้
1. เปิดหน้าเว็บ แล้วเลือกเซิร์ฟเวอร์
2. วางไฟล์ CSV / Excel (ชื่อไฟล์มี PCSEA, PCTH, MSEA, MTH ระบบจะแยกเซิร์ฟให้เอง)
3. ผลจะถูกบันทึกขึ้น Supabase ทุกคนที่เปิดเว็บจะเห็นผลล่าสุดของแต่ละเซิร์ฟได้ 7 วันนับจากที่อัปโหลด

## ข้อมูลที่เก็บ
เก็บเฉพาะ Username ในรายชื่อที่ติดตาม พร้อม Wallet Point และประเทศ ไม่ได้เก็บทั้งไฟล์
ตาราง `wallet_snapshots` ดู `schema.sql` · ข้อมูลเก่ากว่า 7 วันจะถูกซ่อนและลบอัตโนมัติเมื่อมีการอัปโหลดใหม่

## แก้รายชื่อ
แก้ที่ตัวแปร `SERVERS` ใน `index.html`
